# 测试策略

## 测试分层

**单元测试**
- 测试单个函数/类的行为
- 使用 mock 隔离依赖
- 覆盖正常路径和异常路径

**集成测试**
- 测试模块间协作
- 使用临时目录和内存存储
- 验证端到端流程

**E2E 测试**
- 完整系统测试
- 启动真实服务
- 通过 HTTP API 验证

## 异步测试

使用 pytest-asyncio 测试异步代码：
- 标记测试函数为 `@pytest.mark.asyncio`
- 使用 `async`/`await` 调用被测代码
- 使用 `asyncio.timeout` 防止测试挂起

## 测试数据

- 使用工厂函数创建测试对象
- 使用 fixture 共享测试资源
- 测试结束后清理临时文件

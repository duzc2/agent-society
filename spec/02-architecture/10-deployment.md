# 部署架构

## 单机部署

**适用场景**
- 个人使用
- 小规模团队协作
- 开发和测试环境

**部署组件**
- Agent Society Server（Python 应用）
- Chrome/Chromium（浏览器自动化）
- 文件系统存储（配置、状态、工作空间）
- 可选：本地 LLM 服务

**资源需求**
- CPU：2 核以上
- 内存：4GB 以上（取决于并发智能体数）
- 磁盘：取决于工作空间文件大小

## 配置管理

**环境变量**
- `AGENT_SOCIETY_CONFIG_DIR`：配置目录
- `AGENT_SOCIETY_DATA_DIR`：数据目录
- `AGENT_SOCIETY_PORT`：HTTP 端口
- `AGENT_SOCIETY_LOG_LEVEL`：日志级别

**配置文件分层**
- 默认配置（随代码发布）
- 本地覆盖（用户自定义，不提交）
- 环境变量（最高优先级）

## 启动流程

1. **解析命令行参数**：数据目录、端口、是否打开浏览器
2. **加载配置**：Config 服务加载所有配置
3. **初始化日志**：根据配置设置日志级别和输出
4. **初始化 Runtime**：创建并初始化 Runtime 实例
5. **初始化 HTTP Server**：创建并启动 HTTP 服务
6. **注册系统智能体**：创建 Root 和用户端点智能体
7. **加载模块**：扫描并加载启用的模块
8. **启动消息循环**：开始处理消息
9. **打开浏览器**（如果启用）：自动打开 Web 界面

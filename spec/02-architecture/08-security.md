# 安全设计

## 代码执行安全

**为什么需要沙箱？**
智能体可能执行用户提供的代码或 AI 生成的代码。如果不加限制，代码可能：
- 删除系统文件
- 访问网络发送敏感信息
- 消耗无限资源导致 DoS

**Python 代码执行沙箱**
- 在独立进程中执行，进程资源受限（内存、CPU 时间）
- 禁止访问文件系统（除临时目录）
- 禁止网络访问
- 禁止执行系统命令
- 执行时间限制（默认 30 秒）

**JavaScript 代码执行沙箱**
- 在 headless Chrome 的隔离标签页中执行
- 页面没有访问本地存储的权限
- 无法打开新窗口或导航
- 执行时间限制（默认 60 秒）

## 工具权限控制

**为什么需要权限控制？**
不同岗位的智能体应有不同的能力。Root 智能体只能管理组织，不能执行代码。普通智能体可以执行代码，不能删除其他智能体。

**权限实现**
- 岗位配置可用工具组列表
- 工具调用前验证智能体是否有权限
- 工具执行时传递 agent_id，可以审计和限制

## API 安全

**输入验证**
- 所有 API 参数使用 Pydantic 模型验证
- 文件路径规范化，防止目录遍历攻击
- JSON 大小限制，防止超大请求

**敏感信息保护**
- API Key 在日志中脱敏显示
- 配置文件中的敏感项保存到 .local.json
- 错误信息不暴露内部实现细节

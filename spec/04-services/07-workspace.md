# Workspace Service 工作空间服务

## 1. 职责

Workspace Service 负责文件存储和管理：
- 管理工作空间的创建和删除
- 提供文件读写接口
- 确保路径安全，防止目录遍历攻击
- 计算空间占用和文件统计

## 2. 内部工作机制

### 2.1 工作空间管理器

**工作空间生命周期**

工作空间管理器维护所有工作空间的集合：
- 缓存已加载的工作空间实例
- 提供单例访问模式
- 管理存储目录结构

**存储位置**

所有工作空间存储在统一目录下：
```
workspaces/{workspaceId}/
```

每个工作空间一个独立目录，通过ID区分。

**获取工作空间**

获取工作空间时：
1. 先检查缓存中是否已存在
2. 如果存在，返回缓存实例
3. 如果不存在，创建新实例并加入缓存
4. 确保同一工作空间只有一个实例在内存中

**创建工作空间**

创建流程：
1. 验证工作空间ID合法（不能包含路径分隔符）
2. 创建工作空间目录
3. 创建元数据子目录（.meta）
4. 初始化全局元数据文件
5. 返回工作空间实例

**删除工作空间**

删除流程：
1. 递归删除工作空间目录及其所有内容
2. 从缓存中移除实例
3. 返回操作结果

### 2.2 工作空间实例

**目录结构**

每个工作空间内部结构：
```
workspaces/{workspaceId}/
├── .meta/              # 元数据目录（隐藏）
│   ├── .meta           # 全局元数据文件
│   └── {filePath}.meta # 各文件的元数据历史
└── {files...}          # 用户文件和目录
```

**路径安全验证**

所有文件操作前必须进行路径安全验证：

验证规则：
1. 拒绝绝对路径（以 / 或盘符开头）
2. 规范化路径（处理 . 和 ..）
3. 检查规范化后的路径是否仍在 workspace 目录内
4. 禁止路径中包含 ../ 向上遍历

示例攻击检测：
- ../../../etc/passwd → 拒绝
- /absolute/path → 拒绝
- file/../../../outside → 拒绝
- subdir/file.txt → 允许

**文件写入**

写入流程：
1. 验证相对路径安全
2. 构建完整路径并规范化
3. 验证完整路径在工作空间内
4. 自动创建父目录（如果不存在）
5. 检测或清理 MIME 类型
6. 写入文件内容
7. 更新文件元数据

MIME 类型处理：
- 如果未提供，根据文件扩展名自动检测
- 去除可能的引号和空格
- 验证格式为 type/subtype

**文件读取**

读取流程：
1. 验证路径安全
2. 检查文件是否存在
3. 获取文件大小和 MIME 类型
4. 支持随机读取（offset + length）
5. 限制最大读取大小（默认 10MB）
6. 根据 MIME 类型决定返回格式

文本文件处理：
- 尝试 UTF-8 解码
- 成功则返回字符串
- 失败则作为二进制返回

二进制文件处理：
- 读取指定范围的字节
- Base64 编码
- 返回编码后的字符串

**文件删除**

删除流程：
1. 验证路径安全
2. 检查文件是否存在
3. 删除文件或目录（递归）
4. 更新元数据（标记为已删除，保留历史）

元数据保留：
- 不直接删除元数据记录
- 标记 deleted = true
- 记录删除时间和操作者

### 2.3 元数据管理

**双层架构**

元数据采用双层存储：
1. 全局元数据：记录所有文件的最新状态
2. 文件级元数据：记录单个文件的完整历史

**全局元数据**

存储在 .meta/.meta 文件中：
- 包含所有文件的最新状态
- 用于快速列出和查询
- 每次文件变更时更新

结构：
```
{
  "files": {
    "path/to/file.txt": {
      "path": "path/to/file.txt",
      "size": 1234,
      "mimeType": "text/plain",
      "operator": "agent-xxx",
      "messageId": "msg-yyy",
      "updatedAt": "2024-01-01T00:00:00Z"
    }
  }
}
```

**文件级元数据**

存储在 .meta/{filePath}.meta 文件中：
- 记录该文件的完整历史
- 每次操作追加一条记录
- 用于审计和恢复

结构：
```
[
  { "size": 0, "operator": "agent-1", "updatedAt": "..." },  // 创建
  { "size": 100, "operator": "agent-1", "updatedAt": "..." }, // 修改
  { "deleted": true, "operator": "agent-2", "deletedAt": "..." } // 删除
]
```

**路径标准化**

元数据中的路径统一使用正斜杠（/），无论操作系统：
- Windows 路径反斜杠转换为正斜杠
- 保证跨平台一致性

### 2.4 MIME 类型检测

**基于扩展名**

常见扩展名映射：
- .txt → text/plain
- .md → text/markdown
- .json → application/json
- .html → text/html
- .py → text/x-python
- .js → application/javascript
- .png → image/png
- .jpg → image/jpeg
- .pdf → application/pdf

**基于内容**

如果没有扩展名或扩展名未知：
- 检查内容是否包含空字节（二进制特征）
- 如果是二进制，标记为 application/octet-stream
- 如果是文本，尝试检测编码

**MIME 类型清理**

处理大模型可能传入的格式错误：
- 去除引号（"application/json" → application/json）
- 去除首尾空格
- 验证包含斜杠（type/subtype 格式）
- 无效时默认使用 application/octet-stream

### 2.5 空间统计

**文件计数**

递归遍历目录：
- 统计所有文件数量
- 统计目录数量
- 跳过元数据目录（.meta）

**空间占用计算**

递归计算：
- 累加所有文件的字节大小
- 不计算目录本身的大小
- 获取最后修改时间

**统计信息结构**
```
{
  "fileCount": 10,
  "dirCount": 3,
  "totalSize": 1024000,
  "lastModified": 1704067200000
}
```

### 2.6 文件列表

**列出目录内容**

流程：
1. 确定目标目录（默认为根目录）
2. 读取目录下所有条目
3. 过滤掉元数据目录（.meta）
4. 获取每个条目的信息（类型、大小、修改时间）
5. 排序（目录在前，然后按名称字母序）

**条目信息**

每个条目包含：
- id: 相对路径
- type: file 或 directory
- name: 显示名称
- updatedAt: 最后修改时间戳
- size: 文件大小（仅文件）
- mimeType: MIME 类型（仅文件）

### 2.7 文本搜索

**搜索流程**

1. 确定搜索目录
2. 递归遍历目录树
3. 只搜索已知文本类型的文件
4. 逐行读取，搜索匹配
5. 返回匹配结果列表

**支持的文本类型**
.txt, .md, .json, .xml, .html, .css, .js, .py, .ts, .java, .c, .cpp, .h, .go, .rs

**匹配选项**
- 区分大小写 / 不区分
- 最大结果数限制（默认 1000）
- 返回匹配行的上下文

**返回格式**
```
[
  {
    "file": "path/to/file.py",
    "line": 42,
    "col": 10,
    "content": "matching line content..."
  }
]
```

## 3. 安全考虑

### 3.1 路径遍历防护

核心安全措施：
- 拒绝任何包含 ../ 的路径
- 规范化后再次检查
- 确保最终路径以工作空间目录为前缀

### 3.2 文件大小限制

配置限制：
- 单个文件最大 100MB
- 单次读取最大 10MB
- 文本搜索最大读取 100KB

超过限制时返回错误。

### 3.3 危险文件过滤

可配置阻止的文件扩展名：
- .exe, .dll, .so, .dylib（可执行文件）
- .bat, .sh, .cmd（脚本文件）

## 4. 配置

```json
{
  "workspace": {
    "maxFileSize": 104857600,
    "maxTextLength": 5000,
    "allowedMimeTypes": ["*"],
    "blockedExtensions": [".exe", ".dll", ".so", ".dylib"],
    "workspacesDir": "workspaces"
  }
}
```

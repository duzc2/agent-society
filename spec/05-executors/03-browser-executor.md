# Browser Executor 浏览器执行器

## 1. 为什么保留 JavaScript 执行？

虽然系统从 Node.js 迁移到 Python，但仍需要 JavaScript 执行能力，因为：
- 访问浏览器 API（DOM、Canvas、WebGL）
- 执行需要在浏览器环境中运行的代码
- 网页自动化和测试

## 2. 内部工作机制

### 2.1 浏览器管理

**单实例模式**

系统启动时创建单个浏览器实例（Chromium），所有 JavaScript 执行共享该实例：
- 减少资源消耗（内存、CPU）
- 避免频繁启动/关闭浏览器的开销
- 统一管理浏览器版本

**实例生命周期**

- 初始化：系统启动时或首次执行时懒加载
- 运行：保持打开状态，处理多个执行请求
- 关闭：系统关闭时优雅关闭

**懒加载机制**

首次执行 JavaScript 时才初始化浏览器：
- 避免系统启动时长时间等待
- 如果未使用浏览器功能，不占用资源
- 使用锁确保并发请求只创建一个实例

### 2.2 上下文隔离

**BrowserContext 隔离**

每次 JavaScript 执行创建新的浏览器上下文：
- 独立的 Cookie 和 LocalStorage
- 独立的会话存储
- 独立的缓存
- 可以单独设置权限

**为什么用上下文而非页面隔离？**

BrowserContext 比单个 Page 提供更彻底的隔离：
- 防止数据泄露到后续执行
- 每个执行环境完全独立
- 更安全地清理资源

**页面创建**

在上下文内创建新页面：
- 设置视口大小（默认 1920x1080）
- 设置设备像素比
- 应用默认超时设置

### 2.3 JavaScript 执行

**执行方式**

在页面中执行 JavaScript 代码：
- 使用 page.evaluate 方法
- 代码在浏览器上下文中运行
- 支持异步代码（Promise / async-await）

**代码包装**

用户代码被包装以捕获结果和错误：

1. 包装为异步函数
2. 添加 try-catch 捕获异常
3. 返回包含 success/result 或 error 的对象
4. 序列化结果以便传回主进程

**返回值处理**

- 支持基本类型：字符串、数字、布尔、null
- 支持对象和数组（可序列化的）
- 复杂对象转为字符串
- undefined 转为 null

### 2.4 Canvas 支持

**提取方式**

如果代码在 Canvas 上绘制，可以提取结果：

方式一：Data URL
- 调用 canvas.toDataURL()
- 返回 base64 编码的 PNG
- 前端可直接显示

方式二：截图
- 对 Canvas 元素截图
- 返回图片二进制数据
- 转为 base64 返回

**返回格式**

```
{
  "success": true,
  "result": JavaScript返回值,
  "canvasData": "base64编码的图片数据"
}
```

### 2.5 网络隔离

**请求拦截**

通过 Playwright 的路由功能拦截网络请求：
- 设置拦截规则匹配所有 URL
- 根据白名单决定是否允许
- 可以修改请求或响应

**白名单策略**

默认阻止所有外部网络请求：
- 允许 data: URL（内嵌数据）
- 允许 blob: URL（本地对象）
- 允许配置的特定域名
- 阻止其他所有请求

**阻止方式**

不允许的请求会被中止：
- 调用 route.abort()
- 返回空响应或错误
- JavaScript 中表现为网络错误

### 2.6 资源限制

**执行超时**

JavaScript 执行有超时限制：
- 默认 60 秒
- 超时后强制终止页面
- 返回超时错误

**页面加载超时**

如果指定了初始 URL 或 HTML：
- 页面加载有单独的超时
- 网络缓慢时可能超时
- 超时后返回错误

**JavaScript 执行超时**

在浏览器内部的执行超时：
- 通过 Playwright 设置
- 防止无限循环
- 与总超时配合

### 2.7 执行流程

**完整流程**

1. **初始化检查**
   - 确保浏览器实例已启动
   - 如未启动，执行初始化

2. **创建上下文**
   - 新建 BrowserContext
   - 设置视口和权限

3. **创建页面**
   - 在上下文中新建页面
   - 设置默认超时

4. **设置网络拦截**
   - 配置路由规则
   - 阻止外部网络访问

5. **加载初始内容**
   - 如果有 HTML，使用 setContent
   - 如果有 URL，使用 goto 导航

6. **监听 Console**
   - 设置 console 事件监听
   - 收集所有 console.log 输出

7. **执行代码**
   - 包装用户代码
   - 在页面中执行
   - 等待完成或超时

8. **提取 Canvas**
   - 如果请求返回 Canvas
   - 提取图片数据

9. **清理**
   - 关闭页面
   - 关闭上下文
   - 返回结果

### 2.8 初始内容设置

**HTML 内容**

直接设置页面 HTML：
- 支持完整的 HTML 文档
- 支持内嵌 CSS 和 JavaScript
- 立即加载，无需网络请求

**URL 导航**

导航到指定 URL：
- 受网络拦截规则限制
- 可能加载失败或被阻止
- 等待页面加载完成

**空白页面**

不提供初始内容：
- 使用 about:blank
- 纯净的 JavaScript 执行环境
- 适合纯计算任务

## 3. 错误处理

### 3.1 超时错误

**执行超时**

- JavaScript 代码执行超过时间限制
- 通常是死循环或复杂计算
- 返回 TimeoutError

**页面加载超时**

- 导航到 URL 时加载缓慢
- 网络问题或页面过大
- 返回 PageLoadError

### 3.2 JavaScript 错误

**语法错误**

- 代码不符合 JavaScript 语法
- 解析失败
- 返回 SyntaxError

**运行时错误**

- 代码执行时抛出异常
- 如 ReferenceError, TypeError
- 返回错误消息和堆栈

**异步错误**

- Promise 被拒绝
- async 函数中抛出异常
- 被包装器的 try-catch 捕获

### 3.3 浏览器错误

**浏览器崩溃**

- Chromium 进程异常退出
- 内存不足或内部错误
- 尝试重启浏览器

**上下文错误**

- 创建上下文失败
- 资源不足
- 返回 ContextError

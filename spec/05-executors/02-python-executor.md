# Python Executor Python 代码执行器

## 1. 为什么需要沙箱？

智能体可能执行用户提供的或 AI 生成的 Python 代码。如果不加限制，代码可能：
- 删除或修改系统文件
- 访问网络发送敏感信息
- 执行系统命令（rm -rf /）
- 消耗无限资源（死循环、大内存分配）

## 2. 内部工作机制

### 2.1 沙箱架构

**进程隔离**

Python 代码在独立的进程中执行，与主进程完全隔离：
- 独立的内存空间
- 独立的文件描述符
- 独立的系统资源
- 进程崩溃不影响主系统

**执行环境**

使用虚拟环境（venv）或系统 Python：
- 可以指定特定的虚拟环境
- 自动激活环境后执行
- 支持自定义依赖安装

### 2.2 安全检查

**静态代码分析**

执行前扫描代码中的危险模式：

危险函数调用：
- os.system - 执行系统命令
- subprocess - 创建子进程
- eval - 动态执行代码
- exec - 动态执行代码
- compile - 编译代码对象
- __import__ - 动态导入

危险模块：
- ctypes - 调用 C 函数
- multiprocessing - 多进程
- socket - 网络操作

文件系统操作：
- 使用绝对路径打开文件（open('/etc/passwd')）
- shutil.rmtree - 递归删除目录

**AST 分析**

使用抽象语法树（AST）检查导入：

1. 解析代码为 AST
2. 遍历所有 Import 和 ImportFrom 节点
3. 检查导入的模块是否在白名单中
4. 检查危险属性访问（如 __subclasses__）

允许的白名单模块：
math, random, datetime, json, re, string, collections, itertools, functools, statistics, decimal, fractions, hashlib, uuid, base64, textwrap, dataclasses, enum, typing, time, calendar, csv, html

**路径安全检查**

如果代码中包含文件操作：
- 检查是否使用绝对路径
- 确保路径在工作目录内
- 阻止向父目录遍历（../）

### 2.3 资源限制

**CPU 时间限制**

设置进程最大 CPU 时间：
- 默认 30 秒
- 超时后进程被强制终止
- 防止死循环和无限计算

**内存限制**

设置进程最大内存使用量：
- 默认 256MB
- 超出后触发内存错误
- 防止内存耗尽攻击

**其他资源限制**

- 文件描述符数量限制（64个）
- 禁用核心转储（防止生成大文件）
- 子进程创建限制

### 2.4 代码包装

**包装器作用**

用户代码被包装在安全环境中执行：

1. 设置资源限制（CPU、内存）
2. 重定向标准输出和标准错误
3. 设置信号处理（超时捕获）
4. 设置工作目录
5. 执行用户代码
6. 捕获执行结果和输出

**输出捕获**

- 重定向 stdout 到内存缓冲区
- 重定向 stderr 到内存缓冲区
- 捕获 print 输出
- 捕获异常信息

**返回值处理**

执行完成后：
- 检查最后执行的表达式值
- 如果有返回值，序列化为 JSON
- 处理不可序列化的对象（转为字符串或忽略）

### 2.5 依赖安装

**安装触发**

如果工具调用包含 packages 参数：
1. 在代码执行前安装依赖
2. 使用虚拟环境的 pip
3. 安装完成后再执行代码

**包名验证**

验证包名合法性，防止命令注入：
- 只允许字母、数字、下划线、连字符
- 阻止包含空格或特殊字符的包名
- 阻止包含路径分隔符的包名

**安装超时**

依赖安装单独设置超时：
- 默认 120 秒
- 防止网络缓慢导致长时间等待
- 安装失败返回错误

### 2.6 执行流程

**完整流程**

1. **安全检查**
   - 扫描危险代码模式
   - AST 分析导入语句
   - 如果失败，返回安全错误

2. **依赖安装**
   - 如果指定了 packages
   - 验证包名
   - 执行 pip install
   - 如果失败，返回安装错误

3. **创建工作目录**
   - 创建临时目录
   - 写入用户指定的文件（如有）
   - 设置目录权限

4. **代码包装**
   - 转义用户代码中的特殊字符
   - 生成包装代码
   - 设置资源限制代码

5. **子进程执行**
   - 创建子进程
   - 在子进程中执行包装代码
   - 设置超时等待

6. **结果收集**
   - 等待进程结束或超时
   - 读取 stdout 和 stderr
   - 解析 JSON 结果

7. **清理**
   - 终止进程（如仍在运行）
   - 删除临时目录
   - 返回执行结果

### 2.7 临时文件处理

**工作目录**

每个执行请求创建独立的临时目录：
- 目录名包含随机字符串
- 位于系统临时目录下
- 执行完成后自动删除

**用户文件**

支持在执行前写入文件：
- 代码可以读取这些文件
- 文件写入临时工作目录
- 支持文本和二进制文件

**保持工作目录选项**

调试时可以配置不删除工作目录：
- 便于查看生成的文件
- 排查执行问题
- 生产环境应关闭

### 2.8 结果返回

**成功结果**

```
{
  "success": true,
  "result": 返回值（可能是null）,
  "stdout": "标准输出内容",
  "stderr": "标准错误内容",
  "exit_code": 0
}
```

**错误结果**

```
{
  "success": false,
  "error": "错误信息",
  "stdout": "已输出的内容",
  "stderr": "错误输出",
  "exit_code": 非零值
}
```

**截断处理**

输出内容可能很大，需要截断：
- stdout 最大 50000 字符
- stderr 最大 10000 字符
- 超出部分显示"（已截断）"

## 3. 错误处理

### 3.1 安全错误

**检测失败**

- 发现危险代码模式
- 导入了不允许的模块
- 包含禁止的函数调用

**处理方式**
- 不执行代码
- 返回安全错误信息
- 记录安全事件日志

### 3.2 语法错误

**解析失败**

- 代码不符合 Python 语法
- AST 解析抛出 SyntaxError

**处理方式**
- 返回语法错误信息
- 包含行号和错误描述
- 不执行代码

### 3.3 执行错误

**运行时异常**

- 代码执行过程中抛出异常
- NameError, TypeError, ValueError 等
- 断言失败（AssertionError）

**处理方式**
- 捕获异常
- 返回异常类型和消息
- 包含部分 traceback

### 3.4 超时错误

**超时情况**

- 代码执行超过时间限制
- 死循环或计算密集型任务
- 网络操作阻塞（如未禁止）

**处理方式**
- 强制终止进程
- 返回超时错误
- 可能丢失部分输出

### 3.5 内存错误

**内存耗尽**

- 分配大量内存（如大列表）
- 超出内存限制

**处理方式**
- 进程被系统终止或抛出 MemoryError
- 返回内存错误信息
- 清理资源

```json
    "maxMemoryMb": 256,

    "allowedModules": ["math", "random", "datetime", "json"]
  }
}
```

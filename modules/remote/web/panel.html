Remote 远程桥接 — 使用说明

🎯 功能概述

Remote 模块将指定的 Agent 的工具调用桥接到远程 SSH 服务器。Agent 会感觉自己完全在远程服务器上运行，但工作区文件操作仍然保持本地。

⚙️ 工作原理

  • 工作区内操作：文件在工作区内的读写操作仍然在本地执行，不受影响。
  • 工作区外操作：所有工作区外的文件操作（读取、列表、搜索、编辑等）和命令执行都会被翻译为 SSH 命令在远程服务器上执行。
  • 透明桥接：Agent 使用相同的工具名称，不需要改变行为，Remote 模块自动判断是否需要远程执行。

📋 配置步骤

  1. 在「Agent 映射」标签页中点击「+ 添加映射」
  2. 在搜索框中输入 Agent 名称 / ID / 角色名快速定位要配置的 Agent（支持键盘 ↑↓ 导航、Enter 选中；已配置的 Agent 会标记「已配置」）
  3. 填写远程服务器的 SSH 连接信息（主机、端口、用户名、密码或密钥）
  4. 点击「测试连接」验证 SSH 连接是否正常
  5. 点击「保存映射」完成配置
  6. 配置立即生效，无需重启

🔧 被拦截的工具

以下工具在 Agent 配置了 Remote 后会被自动拦截并桥接到远程服务器：

exec_command file_read file_read_lines list_files file_info file_line_count file_search search_text edit_file replace_file delete_file move_file copy_file file_create_directory append_file

命令执行工具（自动桥接到远程，**完全等价**：支持交互式输入、长期运行进程）：

localcmd_spawn localcmd_send_input localcmd_read_output localcmd_get_status localcmd_list localcmd_kill

命令在远程执行、输出格式与本地完全一致（[STDOUT]/[STDERR]/[STDIN] 前缀）， 工具语义与本地完全等价（支持交互式输入、长期运行进程）。 sandbox_* 保持本地运行（沙箱只能访问本地工作区，与 Remote 不冲突）。

⚠️ 注意事项

  • 远程服务器需要安装 python3 或 python（用于 edit_file 的文本替换操作）。
  • 远程文件路径使用 Linux 风格（如 /home/user/project/src/main.py）。
  • 连接密码以明文存储在配置文件中，建议使用 SSH 密钥认证。
  • SSH 连接使用 keepalive 保持，空闲超时由 SSH 服务端决定。

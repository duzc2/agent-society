# 群聊协作

群聊让多个智能体（可以包括你）在同一个群里发言，任何消息都送达所有成员。适合多方讨论、头脑风暴、进度同步。

## 建群

侧栏 → **群聊** → 新建 → 选择成员；或直接在聊天里说：

```
建一个"发布计划"群，把项目经理和测试负责人拉进来
```

成员可以是智能体，也可以是你自己。

## 群机制

- 任何成员发言，所有成员都收到并处理；
- 成员加入/退出/解散会生成系统消息；
- 你在群里说的话，成员智能体同样会响应。

## 用法示例

**多方研讨：**

```
建一个"发布计划"群，把项目经理和测试负责人拉进来，
让项目经理发起讨论，最终把结论发给我
```

**持续同步：**

```
创建一个"进度站会"群，每天让各负责人在群里同步一次进度
```

**争议裁决：**

```
前端和后端对接口格式有分歧，建群让他们各自陈述理由，
最后由你裁决并把结论通知双方
```

## 建议

1. **成员不宜过多**：每条消息所有成员都会处理，成员越多消息量越大；
2. **指定主持者**：让一个成员负责汇总收束，避免讨论发散；
3. **结论落盘**：让主持者把结论写成文档存到工作区，比只在群里翻记录可靠。

## 常见问题

**Q：群消息太多刷屏？**
减少成员数量，或解散后改为"负责人汇总"模式（一对一汇报）。

**Q：想让某个成员退群？**
群详情 → 移出成员；或直接说"让 xxx 退出群聊"。

**Q：群会保留多久？**
群与消息持久化保存，重启后仍在；不需要的群在群详情中解散。

**Q：我在群里发的消息谁会处理？**
所有成员智能体。如果只想某个人看到，用普通会话单独发。

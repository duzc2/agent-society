# 快速上手

带你完成第一次完整的智能体协作体验。

## 第 1 步：确认服务就绪

打开界面，确认右上角 LLM 状态为**已连接**。未配置时按设置窗口提示完成。

## 第 2 步：提交第一个需求

![输入需求](../../images/输入需求.png)

在聊天输入框输入，例如：

```
帮我查一下北京今天的天气，并给出穿衣建议
```

点击发送。

## 第 3 步：观察组织

![首页](../../images/首页.png)

Root 会创建一个岗位和一名负责智能体，把任务交给它。左侧**组织**面板实时显示岗位树和各智能体状态：

![组织架构](../../images/组织架构.png)

## 第 4 步：互动

- **插话**：随时补充信息，智能体会在处理过程中看到；
- **观察协作**：复杂任务会出现多个智能体，对话流里能看到它们之间的往来；
- **查看状态**：头像旁的标识显示空闲 / 等待 LLM / 处理中。

## 第 5 步：接收结果

![查天气](../../images/查天气.png)

任务完成后，结果出现在聊天区。若有文件产出（如 HTML 报告），在**工件**面板查看或直接在浏览器打开。

## 第 6 步：管理产出

![推荐旅游路线报告](../../images/推荐旅游路线报告HTML内容.png)

工件面板可以：预览各类文件、在线编辑、上传文件供智能体使用。

![工作](../../images/work.png)

## 第 7 步：长期使用

任务完成后组织不会消失，智能体继续在岗位上。之后的正确用法：

- 同类工作直接找同一个智能体，接着上次继续（它记得上下文）；
- 工作量大了，在组织视图中给岗位增加智能体或增加下级岗位；
- 不再需要某项工作时，删除对应岗位，其智能体一并终止。

## 建议

1. **需求写具体**：目标、产出形式、约束条件说清楚；
2. **别急着打断**：复杂任务需要时间，观察对话流确认在推进；
3. **善用插话**：执行中补充关键信息，比事后返工效率高；
4. **大任务分阶段**：先要方案再要实施，每个阶段可验收。

## 常见问题

**Q：发送后没有任何反应？**
检查 LLM 状态是否已连接；查看错误提示详情。

**Q：智能体创建了很多个，正常吗？**
复杂任务会拆分多个岗位协作。若认为过度，直接说"不需要这么多角色，你自己完成"。

**Q：想让它停下？**
组织视图 → 智能体属性 → Abort 中止当前动作；或直接发消息说明。

**Q：结果文件在哪？**
工件面板；也可以在系统 `agent-society-data/workspaces/` 目录找到原文件。

**Q：任务完成了，组织要删掉吗？**
不用。组织与智能体长期存在，同类工作直接继续用。确定不再需要时，在组织视图中删除对应岗位。

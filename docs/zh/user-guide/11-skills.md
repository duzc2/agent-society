# 技能系统

技能是可复用的能力包：一份"怎么做某类事"的说明，加上可选的脚本。绑定到岗位后，该岗位的智能体长期自动使用。

## 技能来源

- **智能体自建**：智能体在工作中总结出有价值的方法后，会自己创建技能沉淀下来；
- **ModelScope 安装**：界面技能管理 → 安装，输入技能 ID；
- **Git 导入**：从 Git 仓库导入，适合团队内部共享；
- **空白创建**：技能管理中"空白创建"，在界面表单里填写说明与内容。

## 界面操作

侧栏 → **技能**：

| 操作 | 位置 |
|------|------|
| 浏览技能内容 | 技能总览 |
| 安装/卸载/启停 | 技能管理 |
| 把技能配置给岗位或智能体 | 绑定面板 |
| 复制一份来改 | 技能管理 → 复制 |

## 要点

1. **先绑定再使用**：未绑定的技能不出现在智能体的知识里；
2. **启用状态**：安装后默认禁用，先启用再绑定；
3. **岗位级绑定**共享给该岗位所有智能体；智能体级绑定只影响一个。

## 写法建议

- 说明写清**何时用、怎么用、边界在哪**——智能体靠这段文字决定何时启用这个技能；
- 一个技能一个主题，不要把所有方法堆进一个大技能；
- 纯说明、没有脚本的技能同样有价值（沉淀流程性知识）。

## 技能与记忆

智能体把重复任务的最佳实践固化为技能，同类任务直接复用。你观察到智能体某类任务做得好，可以让它"把这套方法整理成技能"，之后长期受益。

## 常见问题

**Q：绑定了技能，智能体好像不知道？**
检查技能是否处于启用状态（管理面板里切换）；确认绑定的是智能体所属的岗位或智能体本身。

**Q：智能体没选我装的那个技能？**
技能说明决定智能体是否选用。把说明改得更贴合你要的任务描述；或在提需求时点名："用 xxx 技能完成……"。

**Q：安装 ModelScope 技能失败？**
确认网络可达 modelscope.cn；技能 ID 是否正确。

**Q：想改智能体创建的技能？**
技能管理 → 复制 → 修改副本；或技能总览中直接查看内容，通过绑定面板调整归属。

**Q：技能里的脚本会执行什么？**
脚本在工作区内执行，遵循工作区的安全约束。安装来源不明的技能前先在技能总览里看一遍内容。

**Q：想自己做一个技能？**
技能管理 → 空白创建，按表单填写；技能本体是一份说明，描述"何时用、怎么用、边界在哪"。写法见上面的建议。

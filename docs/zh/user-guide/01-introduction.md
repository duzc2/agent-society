# 简介

## 概述

Agent Society 是一个基于大语言模型（LLM）的**自组织多智能体协作系统**，以网页形式使用。

你用自然语言提出目标，系统中的智能体自动组建团队、分工执行、交付结果。整个过程在界面上实时可见，你随时可以插话、纠偏、追加要求。

## 设计理念

系统完全模拟人类管理企业的方法。使用它时，把自己当成管理者：考虑如何建立自己的组织——设哪些岗位、招什么人、怎么分工。

**确定岗位**：每个智能体必须在岗位上。岗位是一份明确的职位定义，一个岗位可以配置一名或多名智能体。岗位可以增加、减少，职责可以修改；岗位变化时，其上的智能体随之调整。

**长期工作**：系统没有新建会话的能力，也不为每个任务另起一批智能体。正确的使用方式：为每一种工作创造一个岗位，长期使用这个岗位上的智能体。智能体在长期工作中积累记忆、沉淀技能，越用越熟练。

**Root 只建组织，不做工作**：根智能体（Root）是组织的组建者。它不亲自处理任何工作，只负责分析需求、设立岗位、在岗位上创建智能体、把任务分派下去。

**组织即公司**：每个组织都是一家"独立公司"——有自己独立的岗位架构和团队，单独管理。组织之间也可以合作：把不同组织的智能体拉进同一个群聊、互相委派任务。

**层层建团队**：不只是 Root，每个智能体都可以建立下级岗位，并在岗位上创建智能体——像企业的部门主管带自己的团队。

**招聘解聘零成本**：这是与人类企业唯一的区别。智能体是虚拟员工，招聘和解聘的成本接近 0——需要人手就设岗位招人，不需要就解聘，大胆按业务调整编制。

对使用方式的影响：

- 同一类工作固定交给同一个岗位，不需要每次重新交代背景——在岗智能体记得上下文；
- 工作量增大时，给岗位增加智能体或增加下级岗位；业务收缩时，减少岗位；
- 新需求优先交给在岗的智能体在原有基础上继续，而不是推倒重建；
- 需求交给 Root，Root 只负责组建组织；真正干活的是岗位上的智能体。

## 工作方式

```
你（浏览器界面）
 │  输入需求
 ▼
根智能体（Root）── 理解需求，指派一个负责人
 │
 ▼
需求负责人 ── 视工作量决定：自己完成，或组建下级团队
 │
 ├──────┬──────┐
 ▼      ▼      ▼
成员A   成员B   成员C
 │
 ▼
结果回传 → 你在界面看到回复和产出文件
```

- 智能体之间互相沟通、互相委派，你能在聊天区看到每一条往来消息；
- 任务产出的文件（报告、网页、图片……）在界面的**工件**面板中查看、下载；
- 每个智能体有头像、名字和状态（空闲/处理中），复杂任务可以观察到多个智能体同时工作；
- 组织与智能体长期存在：任务完成后组织保留在侧栏，下次直接继续。

## 核心概念

| 术语 | 含义 |
|------|------|
| **智能体（Agent）** | 在岗位上工作的成员。有名字、头像、状态，能收发消息、使用工具；长期在岗，积累记忆与技能。 |
| **岗位（Role）** | 职位定义。每个智能体必须在岗位上；一个岗位可配置一名或多名智能体，岗位可增减、职责可修改。每个智能体都能建立下级岗位并在岗位上创建智能体。 |
| **根智能体（Root）** | 组织的组建者。你提的需求都先给它，它只负责建组织、设岗位、创建智能体、分派任务，不亲自做任何工作。 |
| **组织** | 智能体和岗位组成的团队结构。每个组织是一家"独立公司"，单独管理；组织之间可以合作。 |
| **任务** | 你的一次需求。相关消息、产出文件都归在这个任务下。 |
| **工作区** | 任务专用的文件夹。智能体把产出文件放在这里，你在界面上查看。 |
| **群聊** | 多个智能体（可以包括你）共同参与的多向对话。 |
| **技能** | 智能体沉淀的工作方法，可复用。智能体会自己创建技能，你也可以安装。 |
| **模块** | 给智能体增加现实操作能力的开关：浏览器控制、本地命令、远程服务器等。 |
| **组织模板** | 预设的团队结构（软件开发团队、内容运营编辑部等），Root 组建组织时优先参考。 |

智能体还具备记忆能力：重要的信息会记住，有价值的工作方法会沉淀为技能，跨任务复用。

## 安全边界

- 智能体默认只能读写自己任务的工作区文件夹，访问电脑上其他文件需要你在界面中明确授权；
- 浏览器控制、本地命令、远程连接等能力由模块开关控制，不启用就没有；
- 智能体执行高危本地命令时会请求你确认。

## 常见问题

**Q：什么任务适合交给它？**
目标能说清楚、结果能验收的任务。需求越具体，结果越好（详见[使用场景](05-usage-scenarios.md)）。

**Q：我需要会编程吗？**
不需要。所有操作都在网页界面上完成；唯一的技术动作是安装启动（见下一章）。

**Q：智能体会访问我的私人文件吗？**
默认不会。它只能访问任务工作区；工作区之外的文件需要你在界面上逐个文件夹授权。

**Q：运行期间我能做什么？**
随时插话补充信息、纠正方向；可以中止某个智能体当前的工作；可以查看和下载任何产出文件。

**Q：每次任务都要新建组织吗？**
不需要。为每一类工作固定一个岗位、长期使用；在岗智能体记得之前的工作，直接提新要求即可。业务变化时用组织视图增减岗位。

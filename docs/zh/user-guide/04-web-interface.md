# Web 界面指南

启动服务器后访问 `http://localhost:3000/web/`。手机访问会自动切换到移动版界面，功能一致，本篇以桌面版为准。

## 布局

```
┌──────────┬─────────────────────────┬───────────────┐
│          │                         │               │
│ 侧栏      │       聊天区            │   属性面板     │
│ (导航)    │   (消息流 + 输入框)      │  (按需弹出)    │
│          │                         │               │
└──────────┴─────────────────────────┴───────────────┘
```

## 侧栏

| 入口 | 用途 |
|------|------|
| **首页** | 系统概览：智能体总数、正在工作的数量 |
| **聊天** | 与智能体的会话，你的主要工作区 |
| **群聊** | 多智能体共同参与的群 |
| **组织** | 当前组织架构：岗位树、每个智能体的状态和详情 |
| **工件** | 任务产出的文件：预览、编辑、下载、上传 |
| **技能** | 查看和管理智能体的技能 |
| **模块** | 扩展能力开关（浏览器、命令行、SSH 等） |
| **模板** | 组织架构模板的管理 |
| **设置** | LLM 服务、系统参数 |

## 聊天区

- 支持消息渲染：Markdown、代码高亮、图片、图表、公式；
- 发送目标默认为当前会话的智能体；在组织视图中选中某个智能体后再输入，消息直达它；
- **插话**：智能体正在干活时你发的消息不会丢失，它会在处理过程中看到；
- 长对话可用消息导航快速跳转，支持导出会话内容。

## 组织视图

像管理一家公司一样，在组织视图里管理每一家"公司"：

- 每个组织独立成一个团队，在侧栏里切换，单独管理；
- 树状展示岗位与智能体：展开岗位看到下属岗位和智能体；
- 点击智能体打开**属性面板**：状态、待办事项、设定信息；
- 常用管理操作在这里：给智能体配下级岗位、改岗位职责、**中止**（Abort）某个智能体当前的动作。

组织之间的合作：创建群聊时可以邀请任何组织的智能体；群里和私聊里都可以把任务委派给其他组织的智能体。

## 工件面板

任务产出的文件都在这里：

- 树形浏览工作区文件夹；
- 预览各类文件：文本、代码、Markdown、JSON、网页（可直接运行）、图片、音视频、PDF；
- 在线编辑文本文件；
- 上传本地文件到工作区，供智能体使用。

## 群聊面板

创建群、邀请/移出成员、解散群；群消息与个人消息分开展示。详见[群聊协作](06-group-chat.md)。

## 技能面板

- 技能总览：已安装的技能及来源；
- 技能管理：安装（从 ModelScope）、卸载、启停；
- 绑定：把技能配置给某个岗位或智能体。

## 模块窗口

每个模块有自己的管理面板（如浏览器的标签页面板、命令行进程的控制台）。侧栏 → **模块** 打开。

## 错误提示

出错时界面弹出提示；点击可看详情（错误信息、时间、相关智能体），反馈问题时把详情附上。

## 操作速查

| 我想…… | 操作 |
|--------|------|
| 提交新需求 | 聊天区直接输入发送 |
| 查看组织结构 | 侧栏 → 组织 |
| 给某个智能体留言 | 组织视图选中它 → 聊天输入发送 |
| 查看任务产出文件 | 侧栏 → 工件 |
| 修改 LLM 服务 | 侧栏 → 设置 → LLM 配置 |
| 启用某个扩展能力 | 侧栏 → 模块 → 启用 |
| 让智能体停下手头工作 | 组织视图 → 智能体属性 → Abort |
| 上传文件给智能体用 | 侧栏 → 工件 → 上传 |

## 常见问题

**Q：聊天区看不到图片/图表？**
部分内容渲染依赖网络资源，检查网络；或直接在工件面板打开原文件。

**Q：找不到某个任务的文件？**
工件面板按任务切换工作区，先确认选中的是目标任务。

**Q：界面数据不刷新？**
界面靠心跳机制自动更新，一般几秒内同步。长时间不刷新可刷新页面，任务状态不会丢失。

**Q：手机上能用吗？**
能。手机浏览器访问同一地址，自动进入移动版界面。

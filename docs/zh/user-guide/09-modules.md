# 模块扩展

模块给智能体增加现实操作能力：控制浏览器、执行本地命令、连接远程服务器等。每个模块是一个开关，不启用就没有对应能力。

## 启停

侧栏 → **模块** → 启用/禁用。部分模块首次使用时自动加载，无需重启。

> 模块涉及真实系统操作，按需启用：不用的保持关闭。

## 内置模块

| 模块 | 用途 | 什么时候启用 |
|------|------|--------------|
| **chrome** | 控制浏览器：打开网页、点击、填表、截图、读取页面内容 | 网页操作、数据采集、网页测试 |
| **localcmd** | 执行本地命令：运行脚本、转换文件、长任务 | 需要用到本机工具（ffmpeg、python 等） |
| **ssh** | 远程服务器：执行命令、传文件 | 管理远程机器、部署服务 |
| **ui_page** | 在你的界面上即时生成小组件 | 让智能体做天气挂件、看板这类界面 |
| **automation** | 控制鼠标键盘、操作桌面软件 | 操作没有网页/接口的桌面程序 |
| **document** | 读取 docx/pdf 等文档 | 处理文档资料 |
| **light-ocr** | 图片文字识别 | 扫描件、截图中的文字 |
| **message_tools** | 智能体可查阅彼此的对话记录 | 提升协作透明度（不想开放就不启用） |
| **sandbox** | 隔离沙箱中运行命令 | 执行来路不明的代码 |
| **remote** | 远程进程管理 | 配合 ssh 管理远程长任务 |

## 用法示例

### 浏览器（chrome）

启用后直接提需求：

```
打开 GitHub 上 agent_society 仓库的 Issues 页面，统计 open 状态的 issue 数量
```

智能体会自己开标签页、导航、读取内容、汇总结果。

### 本地命令（localcmd）

```
用 ffmpeg 把工作区里的 demo.mp4 压缩为 720p，完成后告诉我输出文件大小
```

命令进程的输出智能体自己会读；长任务期间它会持续跟进，进程状态变化会自动通知它。

### 界面组件（ui_page）

```
给主界面加一个天气挂件，显示北京未来三天天气
```

智能体生成组件直接注入你的界面，刷新后仍生效（在模块面板可管理）。

### 远程服务器（ssh）

启用后在 ssh 面板添加主机信息（地址、账号），然后：

```
把工作区里的报告部署到我配置的那台服务器上
```

## 安全

- **localcmd / sandbox / automation / ssh** 赋予智能体操作真实系统的能力，只在需要时启用；
- 高危本地命令执行前会请求你确认；
- 智能体访问工作区之外的本地文件，需要你在工作区文件访问面板中单独授权；
- **message_tools** 开启后智能体互相可读对话记录，介意则不启用该模块。

## 常见问题

**Q：启用了模块，智能体说没有对应能力？**
模块启用后新建的岗位才默认带上新工具。对已有岗位：组织视图 → 打开岗位详情 → 配置 → 工具组，勾选新工具组。

**Q：chrome 模块打不开浏览器？**
检查本机是否安装 Chrome；面板中有连接状态提示。无头模式（headless）配置在模块管理中切换。

**Q：ssh 连不上？**
在 ssh 面板确认主机配置（地址、端口、账号密码或密钥）；先手动 ssh 一次确认网络可达。

**Q：智能体执行命令我不想让它继续？**
组织视图 → 该智能体 → Abort 中止当前动作；localcmd 面板可直接终止进程。

**Q：模块启用后想收回权限？**
侧栏 → 模块 → 禁用。禁用后智能体立即失去对应工具。

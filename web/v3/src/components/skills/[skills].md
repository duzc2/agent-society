技能界面目录。
包含技能管理窗口、技能总览面板、岗位与智能体技能配置面板，以及窗口单例管理代码。
这里的界面只负责技能资产浏览和配置入口，不承担系统设置窗口职责。
主要文件：
- `SkillManagerDialog.vue`：技能管理主窗口，提供浏览列表、安装卸载入口、总览页切换。
- `SkillOverviewPanel.vue`：技能与岗位/智能体绑定总览。
- `SkillBindingPanel.vue`：岗位或智能体的技能可用性配置面板。
- `skillManagerWindow.ts`：技能管理窗口单例打开逻辑。
子目录：
- custom/：自定义技能界面，包含自定义技能列表标签、编辑窗口和文件树。
- git/：Git 导入技能界面，包含导入对话框和启停管理。
